How it works

  1. Hold & ask

    Hold Ctrl+Alt+Space in any game and ask your question. Local Whisper speech-to-text transcribes it, so your audio never leaves your PC.

  2. Game detected

    It spots the game from your Steam, Epic or GOG installs. Or just say I'm playing X.

  3. Wiki + your AI

    It fetches that game's wiki pages and Claude answers through Claude Code on your existing Pro/Max plan (no API key, about 0.1¢ and 3–4 seconds per ask), or your own Ollama, LM Studio or OpenAI key.

  4. Hear it

    The answer is spoken aloud by a natural offline voice and shown in a small box on your second monitor.

Things you can ask

Talk to it the way you'd ask a friend on the couch who has read the whole wiki and knows not to ruin it.

Features

Listen mode

No key to hold. Press Ctrl+Alt+L, then just say Lorekeeper, …. Follow-ups right after an answer don't need the name.

Spoiler-safe notes

Progress notes are kept per game, so answers stop where you are.

Exclusive fullscreen

Voice input and DXGI screen capture work without leaving fullscreen.

10-minute memory

The screen is remembered (a frame every 10 s for 10 minutes, plus the last 5 seconds), so what did that sign say two minutes ago? works. Say remember this as the vault code to keep one for good.

Gear tracker

Hover an item and say save this as my helm. Later, is this better than my helm? compares stat by stat for your build. Made for Diablo, works with any game's tooltips.

Learns as you play

It notes your class, build and progress from what you ask, so answers fit your run and stay spoiler-safe.

Pin a game

Tray menu to pin the game for emulators or when detection picks the wrong match.

Your AI, free & open

Claude Code on your Pro/Max plan, a free local model in Ollama or LM Studio, or any OpenAI-compatible key: pick it in the tray under AI. All the code is on GitHub.

Install

Requirements

  • Windows 10 or 11 (Mac coming soon)
  • Claude Code (Pro/Max), or your own Ollama / LM Studio / OpenAI key
  • That's it: Lorekeeper sets up its voice (and Claude Code, if that's your pick) on first run
Download for Windows

Run Lorekeeper-Setup.exe: no admin prompt, about 85 MB. If Windows says "Windows protected your PC", click More info → Run anyway (the installer isn't code-signed yet).

Lorekeeper starts in the tray. Launch a game and hold Ctrl+Alt+Space.
